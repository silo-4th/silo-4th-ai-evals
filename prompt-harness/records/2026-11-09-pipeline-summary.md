# 프롬프트 검증 결과 정리: 입력 → 프롬프트 → 출력 → 검증 수치 → 토큰 (2026-11-09)

이 문서는 트랙 4개(A 답변, B 요약, C 서술형 채점, D 퀴즈 생성)마다 다음 다섯 가지를 한곳에 모았습니다.

1. 어떤 입력 데이터를 넣었는가
2. 어떤 프롬프트(지금 서비스 문장과 최종 추천 문장)를 거쳤는가
3. 실제로 어떤 결과가 나왔는가(같은 입력의 출력 비교)
4. 검증 수치
5. 호출 1건당 토큰

상세 근거와 실패 사례는 `records/2026-11-08-<트랙>.md`에 있고, 비전문가용 요약은 `records/2026-11-08-overview.md`에 있습니다.

## 0. 공통 사항

### 검증 방법

| 방법 | 대상 | 설명 |
| --- | --- | --- |
| 자동 검사 | 글자 수, 문장 수, keywords 개수, JSON 형식, 금지 표현, 표 크기 | 코드로 판정합니다 |
| AI 판정 | 정확성, 원문 충실성, 힌트 누설처럼 코드로 못 보는 항목 | Opus 5.5(`claude-opus-5-5`)가 항목마다 통과/실패와 한 줄 근거를 냅니다 |
| 라벨 비교 | 트랙 C 채점 결과 | 사람이 정할 라벨 초안과 판정이 같은지 셉니다. 라벨은 PO 검수 전입니다 |
| 사람 검수 | 전 트랙 | `records/*-review.md`에 PO가 볼 목록을 뽑아 두었습니다 |

### 실행 조건 두 가지

| 조건 | 내용 | 수치를 읽는 법 |
| --- | --- | --- |
| API | 서비스와 같은 Anthropic API 호출. 11/8 15:3x KST에 워크스페이스 한도에 걸려 12/1까지 막혔습니다 | 서비스 값으로 볼 수 있습니다 |
| 구독제 CLI | `claude -p`로 같은 모델, 같은 문장을 부릅니다 | 버전 사이의 차이만 근거로 씁니다. 시간, 비용, 토큰은 참고값입니다. JSON 출력은 CLI가 도구 호출로 받기 때문에 입력 토큰이 호출마다 약 0.8~0.9k 더 많고, 출력 토큰도 부풀어 있습니다 |

### 토큰 표 읽는 법

- 값은 호출 1건의 평균입니다.
- "입력 합계"는 캐시 밖 입력, 캐시 쓰기, 캐시 읽기를 모두 더한 값입니다. 캐시가 있는 트랙은 내역을 함께 적었습니다.
- 가격(100만 토큰당 입력/출력): Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50, Opus 5.5 $4/$20. 캐시 쓰기는 입력의 1.25배, 캐시 읽기는 0.1배입니다.
