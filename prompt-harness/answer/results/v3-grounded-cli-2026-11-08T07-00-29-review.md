ORDER BY만 쓰면 기본 프레임이 "처음부터 현재 행까지"라서, LAST_VALUE의 마지막 값이 현재 행 자신이 되기 때문이에요. 단원 예제에서도 `LAST_DEF`에 이개발 행은 이개발, 최코드 행은 최코드가 나왔어요.

파티션 전체의 마지막 값을 받으려면 프레임을 `UNBOUNDED FOLLOWING`까지 넓혀야 해요.

```sql
LAST_VALUE(ENAME) OVER (
  ORDER BY HIREDATE
  ROWS BETWEEN UNBOUNDED PRECEDING
           AND UNBOUNDED FOLLOWING
) AS LAST_ALL
```

이렇게 쓰면 10번 부서의 모든 행에 마지막 입사자인 서인턴이 나와요.

<details><summary>답 280자</summary>

MySQL에서 `LIMIT`은 SELECT 문 맨 끝에 붙여서 결과 행 수를 제한해요. `LIMIT 3`은 처음 3행만, `LIMIT 2, 3`(또는 `LIMIT 3 OFFSET 2`)은 앞 2행을 건너뛰고 3행을 가져와요. 보통 `ORDER BY`와 함께 써요.

```sql
SELECT ENAME, SAL
FROM EMP
ORDER BY SAL DESC
LIMIT 3;
```

이 예제는 급여가 높은 순으로 3명만 가져와요. 다만 `LIMIT`은 이 단원(서브쿼리)에서 다루지 않는 내용이에요.
