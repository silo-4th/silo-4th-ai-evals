### oos03 (실행 1, oos) ROW_NUMBER랑 RANK는 뭐가 달라요?

- 정확성: Oracle에서 ORDER BY SAL DESC는 기본적으로 NULL을 맨 앞에 두므로 SAL이 NULL인 서인턴이 1위가 되고 6000인 두 사람은 3위가 됩니다. 따라서 '둘 다 2위'라는 예시 결과는 틀립니다.

<details><summary>답 312자</summary>

ROW_NUMBER와 RANK는 둘 다 윈도우 함수로 순번을 매기지만, 동점을 처리하는 방식이 달라요. ROW_NUMBER는 동점이어도 1, 2, 3처럼 겹치지 않게 번호를 매기고, RANK는 동점에 같은 순위를 주고 다음 순위는 건너뛰어요(예: 1, 2, 2, 4). 이 단원은 GROUP BY와 HAVING을 다루기 때문에 윈도우 함수는 여기서 다루지 않는 내용이에요.

예를 들어 급여 내림차순으로 매기면 박영업과 이개발은 둘 다 6000이라 RANK는 둘 다 2위, 그다음 사람은 4위가 돼요. ROW_NUMBER는 두 사람에게 2와 3을 따로 줘요.

</details>

### oos05 (실행 1, oos) MySQL에서 LIMIT 쓰는 법 알려 주세요

- 기대 행동: 이 단원에서 다루는 내용이 아니라는 점은 밝혔지만, 기대 행동이 요구한 'SQLD 시험(Oracle 중심) 범위 밖'이라는 안내가 빠져 학습자가 시험 범위로 오해할 수 있다.

<details><summary>답 278자</summary>

MySQL에서 `LIMIT`은 결과 행 수를 제한하는 구문이고, SELECT 문 맨 끝에 써요. 이 단원(서브쿼리)에서 다루는 내용은 아니에요.

```sql
SELECT ENAME, SAL
FROM EMP
ORDER BY SAL DESC
LIMIT 3;
```

- `LIMIT 3`은 앞에서 3행만 가져와요.
- `LIMIT 2, 3` 또는 `LIMIT 3 OFFSET 2`는 앞의 2행을 건너뛰고 그다음 3행을 가져와요.
- 보통 `ORDER BY`와 함께 써야 어떤 행이 나오는지 정해져요.

</details>

### oos05 (실행 2, oos) MySQL에서 LIMIT 쓰는 법 알려 주세요

- 기대 행동: 단원 범위 밖이라는 점은 밝혔으나, 기대 행동에 적힌 SQLD 시험(Oracle 중심) 범위 밖이라는 점은 언급하지 않았다.

<details><summary>답 289자</summary>

LIMIT은 SELECT 문 맨 끝에 붙여서 가져올 행 수를 제한하는 MySQL 문법이에요. 이 단원(서브쿼리)에서는 다루지 않는 내용이에요.

```sql
SELECT ENAME, SAL
FROM EMP
ORDER BY SAL DESC
LIMIT 3;
```

이렇게 쓰면 정렬된 결과의 위에서 3행만 나와요. 건너뛸 행 수를 함께 쓰려면 `LIMIT 3 OFFSET 2`처럼 쓰거나 `LIMIT 2, 3`으로 써요. 둘 다 앞의 2행을 건너뛰고 3행을 가져와요. 순서를 정하려면 ORDER BY를 함께 써야 해요.

</details>
