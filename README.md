# silo-4th AI 평가 기록

silo-4th 서비스에 들어가는 AI 기능을 서비스에 반영하기 전에 시험하고, 그 결과를 남겨 두는 저장소다.

- 프롬프트를 실제로 고치는 작업은 서비스 저장소 [silo-4th](https://github.com/silo-4th/silo-4th)에서 한다. 이 저장소는 무엇을 시험했고 어떤 결과가 나왔는지를 개발자가 확인하는 용도다.
- 하네스는 서비스 저장소의 DB 연결, API 클라이언트, 환경 변수를 그대로 쓴다. 두 저장소를 같은 폴더에 받아 두고 실행한다.

## 평가 목록

| 폴더 | 대상 | 서비스 코드 | 관련 이슈 | 상태 |
| --- | --- | --- | --- | --- |
| [`classify/`](classify/) | 질문 개념 분류 | `lib/llm/tagging.ts`의 `classifyQuestion` | 4-95 | 측정 완료, 서비스 반영 대기 |

답변, 요약, 퀴즈 생성 평가는 시험할 때 폴더를 추가한다.

## 규칙

- 질문 세트의 정답(기대값)은 사람이 검수한다. 검수 상태는 각 폴더의 README "기록" 절에 적는다.
- 실행 결과(`results/`)는 모두 커밋한다. 파일 이름은 실행 시각(UTC)이다.
- API 키와 DB 주소는 서비스 저장소의 `.env` 파일에서 읽는다. 이 저장소에는 넣지 않는다.
